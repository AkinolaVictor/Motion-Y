0. WHAT THIS PAGE IS
----------------------------------------------------------------
The home page is the FIRST impression. Its job is to convince a
recruiter, founder, or peer developer in under 30 seconds that:
  - This is an AI Engineer, not a generic frontend dev.
  - He builds engineered systems, not toy demos.
  - The site has depth — Projects, Lab, Writing are worth visiting.

It is composed of 8 sections in a fixed order. Build the page file
last; build each section file in the order listed below so each
one can be visually checked in isolation.

Reference image: @docs/prototypes/HomeUI.png
Reference doc:   @docs/HomeUI.md
Live reference:  https://ai-port-test.vercel.app/ (for behavior
                 comparison; copy/layout/feel must match the local
                 design system, not the live site's CSS).

2.2 HeroSystemViz.jsx

    faint data flow, code fragments, abstract system architecture.

        nodes.
      - No flashing; opacity transitions only.
    Wrap in a rounded-xl border bg-surface container so it
    matches the terminal block beside it.
