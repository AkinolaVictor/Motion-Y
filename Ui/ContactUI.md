Design the **Contact page** for Akinola Victor's AI Engineer portfolio. Maintain the exact visual language established on the Home, Projects, About, Lab, and Writing pages: **dark-first, premium, minimal, technical, sophisticated, futuristic but professional**.

Use a near-black/charcoal background, soft-white typography, muted gray secondary text, and **one consistent electric-blue/cyan accent**. Use modern sans-serif typography with subtle monospace text for technical metadata. Avoid excessive gradients, glassmorphism, neon effects, stock imagery, or generic contact-page templates.

## PAGE PURPOSE

The Contact page should feel like the final step after exploring Akinola's work. It should be welcoming, confident, and simple while maintaining the technical identity of the portfolio.

The core message:

> **Let's build something.**

The page should encourage recruiters, developers, founders, and potential collaborators to start a conversation.

## HERO / INTRODUCTION

Large heading:

> **Let's build something.**

Supporting message:

> Have an interesting AI problem, idea, or project? Let's talk about it and explore what we can build together.

Keep the copy concise and personal.

Add subtle technical visual elements such as an abstract connection/network visualization or animated data flow. Keep the visual secondary to the message.

## CONTACT INFORMATION

Create a clean contact information area containing:

### Email
Display Akinola's professional email with a clear copy-to-clipboard interaction.

### Social Links
Include:

- GitHub
- LinkedIn
- X
- Other relevant professional platforms

Use recognizable icons with subtle hover animations.

## CONTACT FORM

Create a premium, accessible form containing:

- **Name**
- **Email**
- **What are you working on?**
- **Message**
- **Send Message**

Use clear labels, excellent spacing, visible focus states, validation feedback, and a polished submit interaction.

The "What are you working on?" field can be a select or compact text input with options such as:

- AI Application
- AI Agent
- RAG System
- Developer Tool
- Collaboration
- Job Opportunity
- Other

Keep the form simple and frictionless.

## FINAL VISUAL TREATMENT

Create a strong visual relationship between the introduction and contact form, preferably using an asymmetric two-column desktop layout:

**Message / Contact Information | Form**

On mobile, stack these naturally.

Include subtle animations when:

- Page loads
- Form fields receive focus
- Buttons are hovered
- Form is successfully submitted

Do not over-animate.
