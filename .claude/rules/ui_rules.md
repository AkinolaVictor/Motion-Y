# UI and Style Rules

## General Rules
- Default Style Scheme: dark-first, minimal, sophisticated, technical, futuristic but professional. Use a near-black/charcoal background, soft-white typography, muted gray text, and **one accent color** such as electric blue/cyan. Avoid excessive gradients, glassmorphism, neon effects, stock AI imagery, robots, or generic templates.
-Maintain the exact visual language established on the Home, Projects, and About pages: **dark-first, premium, minimal, technical, sophisticated, futuristic but professional**. Use a near-black/charcoal background, soft-white typography, muted gray secondary text, and one consistent electric-blue/cyan accent. Use modern sans-serif typography with subtle monospace technical metadata. Avoid excessive gradients, glassmorphism, neon effects, stock AI imagery, or generic templates.
- The default style is to be regarded as dark mode
- Find out the best light mode styles by yourself
- Ensure to implement dark, light, and system mode globally across the project
