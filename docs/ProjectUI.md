## PROJECTS PAGE

Intro text:

> **A collection of AI systems, experiments and developer tools.**

Create filter controls:

**All · RAG · Agents · Multimodal · LLM · Developer Tools · ML**

Display projects in a visually varied grid rather than identical cards.

Each project card must contain:

- Thumbnail/image or video preview
- Project name
- Short problem statement
- Technologies
- Status
- GitHub
- Live Demo
- Labels: **Featured, Experimental, Open Source**

Use subtle hover interactions, image transitions, technical metadata, and clear CTA links. Featured projects should receive stronger visual emphasis.

Generate realistic project content covering RAG, agents, multimodal AI, LLM applications, developer tools, automation, evaluation, and ML.

## PROJECT DETAIL PAGE

Create a reusable case-study layout for individual projects.

### Hero
Project name, category, concise description, status/labels, technology tags, GitHub and Live Demo CTAs, plus a large project visual.

### Problem
Clearly explain the real-world problem being addressed.

### Solution
Explain what was built and why it solves the problem.

### Demo
Provide a prominent interactive demo/video area.

### Architecture
Show both a concise explanation and a clean technical architecture diagram. Visually represent components, data flow, AI models, APIs, databases, agents, tools, and external services where applicable.

### How It Works
Show the system workflow step-by-step using a visual process such as:

**Input → Processing → Retrieval/Reasoning → AI → Tools → Output**

Adapt this to each project.

### Technology
Organize technologies by category: AI/ML, frontend, backend, database, infrastructure, APIs.

### Engineering Decisions
Explain important technical choices, alternatives considered, and why particular approaches were selected.

### Evaluation
Show meaningful metrics such as accuracy, retrieval quality, latency, cost, reliability, or task success rate using clean visualizations where appropriate.

### Challenges
Show important technical problems, failures, limitations, and how they were addressed.

### Results
Clearly communicate measurable outcomes and what was learned.

### Future Improvements
Show planned improvements and potential extensions.

### Final CTA
Prominent **GitHub** and **Live Demo** buttons, followed by navigation to the next/previous project.

## CONSISTENCY

Reuse the Home page's navigation, footer, typography, spacing, buttons, cards, badges, colors, animation language, borders, and responsive behavior.

Use subtle purposeful animations and technical micro-details, not decorative effects.

The Projects page should feel like an **AI engineering showcase**, while each Project Detail page should feel like a **technical case study**.

The overall impression should be:

> **“These aren't just demos; these are engineered AI systems.”**

Ensure the entire experience is responsive, accessible, fast, and visually consistent with the existing Home page.
